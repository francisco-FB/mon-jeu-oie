# Jeu de l'oie personnalisable

## Fonctionnalités attendues
- Saisir le nombre d'équipes (entre 2 et 10)
- Bouton « Lancer le jeu »
- Plateau de 63 cases avec les pions de chaque équipe
- Lancer de dé à chaque tour, le pion avance et son déplacement est affiché
- Cases spéciales : oie (on rejoue), pont, puits, labyrinthe, prison, tête de mort (retour départ)
- Cartes actions gagnées sur certaines cases, gardées par l'équipe et jouées quand elle veut : Avance de 3, Passe-tour adverse, Bouclier, Rejoue
- Message de victoire quand une équipe arrive exactement sur la case 63

## Conditions techniques
- En local, sans serveur : on ouvre simplement index.html dans un navigateur
- Langages : HTML, CSS, JavaScript (aucune bibliothèque)
- Fonctionne sur tous les OS (Windows, Mac, Linux)

## Aspect graphique
- Ambiance : jeu de société, couleurs chaudes (beige, rouge, vert)
- Pions de couleur (un par équipe), icônes emoji sur les cases spéciales
